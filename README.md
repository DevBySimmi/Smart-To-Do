🌸 Smart To-Do

«✨ Organize your day • Get things done • Stay happy 💕»

Smart To-Do is a cute and simple desktop task-management application built with Python and Tkinter.

It helps you organize your daily tasks, set priorities, add deadlines, track completed tasks, and keep everything saved automatically.

✨ Features

- 📝 Add new tasks
- 🎯 Set task priority
- 🟢 Low
- 🟡 Medium
- 🔴 High
- 📅 Add due dates
- 🔍 Search tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🧹 Clear completed tasks
- 📊 View task statistics
- 💾 Automatically save tasks
- 🌸 Cute pastel-style interface
- ⚡ Lightweight and easy to use
- 🐍 Built with Python

🛠️ Technologies Used

- 🐍 Python 3
- 🖥️ Tkinter
- 💾 JSON
- 📅 Datetime

No external Python libraries are required.

🚀 Installation

1. Open the project folder

cd Smart-ToDo-Cute

2. Run the application

python main.py

That's it! 🌸

📝 How to Use

Add a Task

1. Enter your task name.
2. Select a priority.
3. Enter a due date in "DD-MM-YYYY" format.
4. Click ＋ Add Task.

Complete a Task

Select a task from the list and click:

✓ Complete

Delete a Task

Select a task and click:

🗑 Delete

Search

Type a keyword in the search box to quickly find your task.

Clear Completed Tasks

Click:

🧹 Clear Completed

to remove all completed tasks.

💾 Data Storage

Your tasks are stored locally in:

tasks.json

The application does not require an online account or database.

📊 Task Statistics

- ⏰ Pending Tasks
